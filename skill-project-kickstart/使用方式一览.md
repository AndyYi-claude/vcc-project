# 项目管理看板工具 · 使用方式

三种方式，选最顺手的一个。

---

## 方式一：拖文件到 Claude 网页版（最简单）

1. 把 `SKILL.md` 文件拖进 Claude 网页版对话框
2. 说："按这个规则帮我生成项目管理看板"
3. 回答 Claude 的问题
4. 把生成的 HTML 代码保存为 `dashboard.html`，双击浏览器打开

**适用**：Claude 网页版用户。无需安装。

---

## 方式二：安装为 Skill（体验最好）

1. 把 `skill-project-kickstart` 文件夹放到 `C:\Users\你的用户名\.claude\skills\` 下
2. 重开 Claude Desktop
3. 输入 `/project-kickstart`
4. 回答 Claude 的问题，它自动生成所有文件到本地

**适用**：Claude Desktop 用户。可管理多个项目，支持 Git 在线共享。

---

## 方式三：我帮你生成

把项目信息发给我（项目名、团队成员、任务分工），我帮你生成好看板文件夹，发你压缩包。

**适用**：不想自己操作，或对 Claude 不熟。

---

无论哪种方式，最后都能拿到一个 `dashboard.html`，双击浏览器打开就是完整的项目管理看板。
