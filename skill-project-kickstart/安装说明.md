# 项目管理看板工具 · 安装说明

## 安装（1 分钟）

1. 复制整个 `skill-project-kickstart` 文件夹
2. 放到这个目录下：`C:\Users\你的用户名\.claude\skills\`
3. 重开 Claude Code

## 使用

在 Claude Code 里输入：

```
/project-kickstart
```

然后回答 Claude 的问题就行。问什么答什么，不用准备任何材料。

## 生成结果

一个文件夹，里面有：
- `dashboard.html`——双击用浏览器打开，交互看板
- 一堆 `.md` 文件——Markdown 版，方便纯文本查看

## 修改

后续要改项目内容，在 Claude Code 里说：

```
帮我更新 XX 看板，张三完成了一个任务
```

Claude 会帮你改文件。
