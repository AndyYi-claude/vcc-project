# GitHub 注册教程（免费 · 2 分钟）

注册 GitHub 后，你的项目管理看板可以生成一个网页链接，同事直接打开就能看。

## 第一步：注册

1. 打开 https://github.com/signup
2. 填邮箱 → 设密码 → 起个用户名（建议英文，比如 zhangsan-work）
3. 验证邮箱 → 完成

## 第二步：告诉我用户名

注册完后回到 Claude Code，告诉我你的用户名。我会帮你：
- 创建项目仓库
- 把看板传上去
- 生成网页链接

之后同事打开链接就能看到项目看板。

## 以后还能做什么

- 多人协作管理同一个项目
- 配企业微信机器人自动更新任务
- 国内同事可同步到 Gitee（码云）免翻墙查看
