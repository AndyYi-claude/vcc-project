# Claude 网页版 · 项目管理看板生成

## 使用方法

**第一步**：把 `SKILL.md` 文件拖进 Claude 网页版对话框（或点附件上传）。

**第二步**：发送这段话：

```
请按这个规则帮我生成项目管理看板，开始问我问题吧。
```

**第三步**：回答 Claude 的问题。

**第四步**：Claude 生成完，把 HTML 代码复制下来，粘贴到记事本，保存为 `dashboard.html`，双击浏览器打开。

---

## 注意

- SKILL.md 文件在这个文件夹里，找到它拖进 Claude 即可
- 保存的文件名必须以 `.html` 结尾
- 后续想改内容，继续跟 Claude 对话就行
