# Claude 网页版 · 项目管理看板生成

不需要装任何东西，复制下面这段话到 Claude 网页版即可。

---

## 使用方法

### 复制这段话给 Claude：

```
你好。请先访问这个项目管理看板生成规则：
https://gitee.com/AndyYi98/vcc-project/raw/main/skill-project-kickstart/SKILL.md

读取后，按照里面的规则帮我做一个项目管理看板。现在开始问我问题吧。
```

### Claude 会怎么做？

1. 读取规则
2. 开始逐一问你项目信息（名称、团队、任务、阶段等）
3. 最后生成一个完整的 HTML 看板代码
4. 你把代码复制下来，粘贴到记事本，保存为 `dashboard.html`
5. 双击用浏览器打开

---

## 一句话版本（适合老手）

```
访问 https://gitee.com/AndyYi98/vcc-project/raw/main/skill-project-kickstart/SKILL.md 按规则帮我生成项目管理看板
```

---

## 注意

- Claude 生成的 HTML 代码很长，复制时确保全选
- 保存文件名必须以 `.html` 结尾
- 生成完可以继续对话，让 Claude 修改
