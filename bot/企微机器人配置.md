## 三、HTTP 请求配置（API 调用）

### 触发 GitHub Actions 工作流

**请求方法**：POST
**请求 URL**：
```
https://api.github.com/repos/AndyYi-claude/vcc-project/actions/workflows/task-complete.yml/dispatches
```

**请求头**：
```
Authorization: Bearer <GITHUB_TOKEN>
Accept: application/vnd.github+json
Content-Type: application/json
```

**请求体**：
```json
{
  "ref": "main",
  "inputs": {
    "task_name": "<从群消息中提取的任务名>",
    "completed_by": "<从群消息中提取的完成人>"
  }
}
```

### GitHub Token 获取

1. 打开 https://github.com/settings/tokens
2. 点击「Generate new token」→ 「Generate new token (classic)」
3. Note 填 `VCC Bot`
4. 勾选 `workflow` 权限
5. 生成后复制 Token（只显示一次）
6. 将 Token 填入上方 `Authorization: Bearer ` 后面
