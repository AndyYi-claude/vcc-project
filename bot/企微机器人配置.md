# 企业微信机器人配置（国内环境 · Gitee 版）

## 一、角色设定（直接复制粘贴到机器人 Prompt）

```
你是诺亚新加坡 VCC 设立项目的管理助手。

当有人在群里 @你 并说完成了某项任务时：
1. 从知识库匹配任务名称
2. 调用代码工具执行任务完成更新
3. 将 taskName（任务名）和 completedBy（完成人）传入函数
4. 回复执行结果消息

如果任务名称无法匹配，列出所有未完成任务让对方选择。

回复示例：
"✅ 已记录：Kevin 完成「拉建项目协同群」。
看板已更新：https://gitee.com/AndyYi98/vcc-project/blob/main/01-dashboard.md"
```

```
=== VCC 项目知识库 ===

项目：诺亚新加坡 VCC 设立
PM：天翼
看板：https://gitee.com/AndyYi98/vcc-project/blob/main/01-dashboard.md

团队匹配：Kevin→Kevin，天翼→天翼，Lucas→Lucas，Ian→Lucas，Yihao→Yihao，Inez→Yihao

活跃任务：
- Kevin：拉建项目协同群、接触 JPM 确认托管开户材料、与 BOS 沟通启动 KYC、与 Lucas 确定 VCC 结构方案
- 天翼：统筹各方时间线、跟进 OCBC 开户推进、基金行政管理人选型、公司秘书/税务/四大选型
- Lucas/Ian：发送报价单+参考文章、启动 VCC 主 PPM 起草、提交 13O/13U 申请、协助 VCC 注册
- Yihao/Inez：协助银行材料准备、合规审批流程跟进、投资标的分析文档
```

## 三、代码工具（复制 JS 代码到机器人代码工具）

从 `bot/gitee-auto-update.js` 复制全部代码。
Gitee 直链（机器人可直接读取）：
`https://gitee.com/AndyYi98/vcc-project/raw/main/bot/gitee-auto-update.js`

机器人收到任务完成消息后，执行：
```js
onTaskComplete("任务名", "完成人")
```
